# Lab 23 — Auto-Config Versus Ownership

| Boot / auto-config gift | Still owned by the team |
| --- | --- |
| Default DataSource / JPA wiring | Schema design, migrations, and repository rules |
| Default MVC / Web stack | URI design, controllers, and domain boundaries |
| Default validation / conversion | Domain validators and business invariants |

## One-sentence rule
Boot can wire infrastructure, but the team still owns every domain rule and boundary decision.
