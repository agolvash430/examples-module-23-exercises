# Lab 23 — Boot Starters Inventory

| Starter | Why for CRM lab |
| --- | --- |
| spring-boot-starter-web | Provides MVC, JSON, and controller support so the CRM can expose REST endpoints. |
| spring-boot-starter-actuator | Gives health/info endpoints for observability and basic operational insight during development. |
| spring-boot-starter-test | Supplies JUnit, Mockito, and Spring Boot test utilities for writing isolated and integration tests. |
| spring-boot-starter-validation (optional) | Enables annotation-based validation for request DTOs and domain input checks. |
